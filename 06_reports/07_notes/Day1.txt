Data analytics is the process of studying data to find useful answers.
A data analyst helps businesses make better decisions.
Main tools: Excel, SQL, Power BI.
A data analyst studies data to answer business questions.
They clean data before using it.
They make charts or dashboards to show the results.
They help people make better decisions.
Excel is used to organize and clean data.
SQL is used to get data from databases.
Power BI is used to make dashboards and charts.
Python is used later for deeper analysis.
First, learn Excel.
Then learn SQL.
Then learn Power BI.
Then build a small project.
